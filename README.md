# Solo Sees Skate Division — soloseeskate.com

Static storefront for the Solo Sees Skate Division line (Solo Sees Studios LLC).
Hosted on Netlify; every push to `main` deploys to https://soloseeskate.com.

- `index.html` — shop page. Product list lives in the `PRODUCTS` array; set a product's `etsy` field to its Etsy listing URL to switch "Coming soon" to "Buy it now".
- `policies.html` — privacy, terms, shipping, returns, copyright, contact.
- Images: product mockups (`tee_*.png`, `hood_*.png`, `hat_*.png`, `beanie.png`), logos, lookbooks.

Checkout happens on Etsy; orders are fulfilled by Tapstitch. No backend.
